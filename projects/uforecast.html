UForecast – Sentiment-Based Campus Weather Mapping

Role

UI & UX designer, Front-end Developer

duration

January 2024 - April 2024 [4 months]

Tools

HTML • CSS • JavaScript • SVG • OpenWeatherMap API
View Live

Overview

An interactive web app visualizing student sentiment across campus through a dynamic SVG map and real-time weather updates.

The Problem

Students often associate places on campus with moods—stress at the library, peace in the gardens—but there’s no way to visualize this. UForecast turns these emotions into a dynamic, map-based experience that also provides real-time weather insights.

Why This App Was Necessary

  • Enhances emotional awareness on campus
  • Encourages exploration through interactive design
  • Combines utility (weather) with novelty (mood mapping)
  • A personality quiz to match pets with owners

Audience & Goals

Audience

  • Students curious about emotional “hotspots”
  • Newcomers wanting to understand the vibe of spaces
  • Faculty interested in student well-being
  • Campus visitors or prospective students

Goals

  • Interactive campus map with emotion-based reactions
  • Real-time weather panel using OpenWeatherMap API
  • Smooth hover & click animations
  • Clear, fun UI

Design & Development Process

  • Built iteratively: UI evolved as the codebase grew
  • Retroactive wireframes documented the final layout
  • Real-time user feedback informed sentiment labeling and interactions

Tech Stack & Features

Tech Used:

HTML • CSS • JavaScript • SVG • OpenWeatherMap API

Key Features:

  • Interactive SVG Map – clickable zones for sentiment display
  • Real-Time Weather Component – API integration for Coral Gables
  • Sentiment Pop-Ups – mood-based overlays, color-coded
  • Responsive Design – optimized for desktop + touch screens
